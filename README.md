# Personal-Cloud-Server
The goal of this project is to document the things I have learned throughout. It is served for learning purposes.

## Details of The Cloud Server
- 2010 Inteli5-2435M (x86_64 Architecture) Macbook Pro
- Storage and Type: 512GB HDD
- RAM: 4GB
- Weight: 2.04 kg
- Current OS: Linux Mint 21.3 XFCE
- Battery life: Poor
- Condition: Used but Good. 'V' keyboard button does not respond

## The Goal
- Change the distro to smoothly operate the system
- Store photos and videos, and possible some documents to save storage on all devices
- Efficiently manage the system by setting up a automized shutdown and open command to reduce chances of exploding battery
